Chai CSS Engine Guide

Chai CSS Engine is a lightweight runtime utility-class engine inspired by Tailwind CSS. Instead of generating CSS files ahead of time, it scans your HTML for classes that start with chai-, translates each class into style rules, and applies the result as inline styles.

Purpose

Learn how utility parsing works in a simple, readable architecture.

Input

Utility tokens like chai-p-20 and chai-text-blue-600.

Output

Inline styles written directly to matching elements in the DOM.

How The Engine Works

  1. Bootstrap: startEngine() initializes runtime.
  2. Extract: extractClasses() collects every class beginning with chai-.
  3. Generate: generateStyle(className) maps token parts into a style object.
  4. Apply: applyStyle(element, styleObject) writes final values through element.style.

Class: chai-text-blue-600 Token type: text Resolved value: #2563eb Result: element.style.color = "#2563eb"

Troubleshooting & Notes

  • Ensure classes start with chai-; otherwise they are ignored by the extractor.
  • Processing currently runs once on DOMContentLoaded; dynamic elements added later are not auto-styled.
  • Dash-based parsing limits complex CSS values represented as one token.
  • Styles are applied inline, so later inline assignments can override earlier values.
