Chai CSS Engine: Start Here

A simple utility-class engine. Add classes with chai- prefix, and styles are generated at runtime.

Step 1: Install dependencies

Run this inside the project root: 

npm install

Then start dev server:

npm run dev

Step 2: Clean HTML before using

Start with a minimal HTML file and remove old CSS frameworks/classes. 

<!doctype html>
<html>
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Chai App</title>
  </head>
  <body class="chai-bg-slate-50 chai-p-20">
    <h1 class="chai-fs-3xl chai-text-slate-800">Hello Chai</h1>

    <script type="module">
      import { startEngine } from "../src/index.js";
      startEngine();
    </script>
  </body>
</html>

Step 3: Utility syntax

Pattern: chai-<utility>-<value>

  • chai-bg-red-500 → background color
  • chai-text-slate-700 → text color
  • chai-p-4 / chai-m-8 → spacing from config scale
  • chai-w-320 → numeric becomes px
  • chai-w-50p → p suffix becomes %
  • chai-w-[37px] → arbitrary value

Color examples

Use colors with shades: 50 to 900.

chai-bg-red-100 chai-text-red-700
chai-bg-blue-100 chai-text-blue-700
chai-bg-green-100 chai-text-green-700
chai-bg-slate-200 chai-text-slate-800

Step 4: Customize your design tokens

Edit src/chai.config.js to change prefix, colors, spacing, and font-size scale.
